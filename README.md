# Bird Classifier

Tools for preparing an image dataset and training a bird-species classifier.

## Project layout

- `data/raw/`: original downloaded or collected data (not tracked by Git)
- `data/interim/`: intermediate cleaned data (not tracked by Git)
- `data/processed/`: finalized train/validation/test data (not tracked by Git)
- `src/bird_classifier/`: reusable application code
- `scripts/`: executable dataset and training entry points
- `configs/`: version-controlled training and dataset configuration
- `tests/`: automated tests
- `models/`: local model checkpoints (not tracked by Git)

## Development environment

Create and activate a dedicated Conda environment, then install the project in editable mode:

```powershell
conda create -n bird-classifier python=3.11 pip
conda activate bird-classifier
pip install -e ".[dev]"
```

Install PyTorch separately using the command generated by the official PyTorch installer for the selected CPU or NVIDIA CUDA build.

## Label images

Place images in `data/raw/images/`, then launch the local labeling interface:

```powershell
python scripts/label_images.py
```

Enter a species label and select **Save & next**. Labels are stored in
`data/raw/labels/labels.csv`, and the tool resumes at the first unlabelled image
the next time it opens. Use **Skip** for uncertain images and **Back** to revisit
the preceding image.

## Sample video frames

Place smart-camera videos in `data/raw/videos/`, then extract three reproducible
random candidate frames from every video:

```powershell
python scripts/extract_random_frames.py
```

The JPEGs and `frame_manifest.csv` are created in
`data/interim/candidate_images/`. Use `--seed` to deliberately choose a different
sample, and `--overwrite` only when replacing an existing sample.

To label extracted video frames, run:

```powershell
python scripts/label_images.py --image-root data/interim/candidate_images --labels-csv data/raw/labels/video_frame_labels.csv
```
